# UI audit — 2026-11-06

Audited the Electron application in isolated profiles, preserving the real user's settings and unsaved files.

## Coverage

- Main editor and every Settings section at 1024, 1280 and 1920 window widths (800 height), including Python, Java and C# build settings. Screenshots and horizontal control bounds were recorded under `plans/artifacts/ui-audit/`.
- GUI smoke: 12 checks passed, including missing resources, renderer exceptions and console errors.
- Editor: 18 checks passed, including split panes, resize, file drag/drop and settings application.
- Theme customizer: 18 checks passed, including six built-in themes, previews, saving, restart and failure rollback.
- Folder picker / Explorer: passed welcome, menu, shortcut, cancellation and Material Icon Theme rendering checks.
- Contest / Collections: passed creation, file selection, language templates, status updates and restart persistence.
- Practice: passed provider browsing, statement sanitization, imports, resize grip, Premium restrictions, sample runs and failed-request recovery.
- Official tests: passed read-only inputs/outputs, deletion guards, snapshot restoration, C++/Python AC and WA results, and manual-test editing.

## Changes from this audit

- Allowed editor suggestion/hover widgets to render beyond rounded editor boundaries using Monaco's fixed overflow widget option.
- Unified Collections runtime error and timeout indicators to red, and testing indicators to blue, including icons and badges.
- Codeforces now labels the action `Create file (no samples)` when the statement cannot load, rather than implying sample tests are ready.

## Limits and unresolved observations

No horizontal control overflow or renderer exception was detected in the audited Settings layouts. The first editor line is visible in the captured clean-profile layouts. The exact clipped fragment in the user's earlier screenshot was not reproduced; the widget clipping change addresses a potential cause, not proof of that screenshot's cause.

Codeforces can block automatic statement requests. Its public catalog is available, but this audit does not resolve the upstream restriction or provide missing statements/samples. Open the official page and import samples with Competitive Companion when blocked.

The Collections Runtime Error label represents a stored execution verdict. A screenshot of that badge alone cannot establish the source-code error; the failing test's stderr is needed.

These checks cover the listed views and flows, not every possible file, operating-system scale, theme customization or UI state. This is not a claim that the application is 100% free of UI defects.
