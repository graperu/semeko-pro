# HackerRank C++ in Practice

Open Practice → Platform HackerRank → Category C++. The public C++ track currently returns 44 unique challenges; all are reachable via the existing pagination/search/difficulty controls. Selecting this category defaults the solution language to C++. Official-page navigation respects the selected category.

Public statements, source-provided stubs when available and paired sample input/output blocks use the existing import/run flow. Imported samples are fixed in the UI. Passing local samples is separate from official HackerRank submission and hidden tests. Not all challenges supply a downloadable starter or paired stdin samples through this endpoint; this change does not invent missing stubs/tests or claim full platform judging support for every challenge.

`npm run test:hackerrank:cpp` verifies the 44-item live catalog, runs five real C++ solutions against seven official samples (Input and Output, Conditional Statements, Arrays Introduction, Strings, For Loop), and checks category/default-language/fixed-test import in Electron. All checks passed on 2026-11-07. The public endpoint can change or be blocked.
